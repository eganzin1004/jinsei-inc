# life/ の4つのフォルダ

ライフ部が持つ記録の置き場所。**中身は追跡から外すことを勧める**（`.gitignore.sample` 参照）。
自分以外の人が関わる記録と、心身の記録が入るため。

| フォルダ | 何を書くか | 入口 | 出口 |
|---|---|---|---|
| `mental/` | 「できるようになったこと」と「やめたこと」の蓄積 | セッションを閉じるときに、エージェントが拾って書く | 月次レビューでの棚卸し |
| `journal/` | 印象的なことがあった日のエピソード | 書きたくなったとき（毎日ではない） | 読み返したくなったとき・年次の振り返り |
| `health/` | 体調・睡眠・運動の記録（`YYYY-MM.md`） | 不調があったとき・習慣を測っているとき | 月次レビュー・「去年の同じ時期」を見たいとき |
| `family/` | 家族・パートナー・人間関係のメモ（`topic-name.md`） | 話題に出たとき | 判断が要るとき（相手の事情を思い出す） |

## `mental/growth-log.md` の設計だけ、少し説明する

**増えた側だけを書くログにしないこと。** 「できるようになったこと」だけを溜めると、記録が成長物語だけを生成する装置になり、変化ではなく一貫性を強化する。

やめたこと・興味を失ったこと・もう戻らないと決めたことも、`〔手放した〕` を付けて同じ時系列に置く。

**入口を「自分で気づいたら書く」にしないこと。** 人は自分の達成を割り引いて見るので、自己申告に任せると増えた側すら書かれない。エージェントが拾う側に回す。

## journal/ を日記にしない

毎日書くものにすると、続かなくなった時点で全部止まる。「あとで思い出したい」「誰かに話したいな」と思ったときだけ書く。書かない月があって当然。
