# スキル一覧

自作スキルの台帳です。新しく作ったらここに追記します。

**同梱してあるのは起動口の1本だけです。** スキルは「自分の運用のどこが面倒か」から生えるものなので、他人の面倒事を先に配っても使われません。台帳の形式と、下の1本を見本にして、自分の必要なものを足してください。

> **置き場ルール**: 実体（正）はこのフォルダの `.claude/skills/` に作り、`~/.claude/skills/` には symlink を張ります。symlinkの整合は起動時チェックが毎回検査します。
> **台帳の分担**: このファイル＝自作スキル。外部から取り込んだものの正は `ARSENAL.md`。混ぜると出自が分からなくなり、更新の追いかけができなくなります。

## 儀式を起動するもの

### company

**ファイル**: `.claude/skills/company/SKILL.md`
**呼び出し**: `/company` または「秘書」「タスク」「ダッシュボード」「壁打ち」

組織を起動します。持っているのは**起動手順だけ**で、口調・記録・振り分けの運用ルールは `secretary/CLAUDE.md` が正です。ここに運用ルールを書き足さないこと——2箇所に書くと必ず片方が古くなります。

**依存**: 起動時チェックのスクリプト、タスク・カレンダーの取得手段（後者は任意）

## 追記フォーマット

新しく作ったら、目次に1行足して、下に節を作ります。

```markdown
### スキル名

**ファイル**: `.claude/skills/<name>/SKILL.md`
**呼び出し**: `/<name>` または「自然言語のトリガー」

何をするスキルか。1〜3行。

**依存**: 外部サービス・スクリプト・他のスキルへの依存があれば書く
```

## どの粒度で作るか

作りすぎると台帳が死にます。以下を目安にしています。

- **同じ手順を3回やったら作る。** 1回目2回目は手でやる。3回目に「また同じことをしている」と気づいた時点が作り時です
- **判断が要る作業はスキルにしない。** スキルは手順を固定する道具なので、毎回考えるべきことを固定すると考えなくなります
- **1スキル1目的。** 「あれもこれも」になったら分けるか、そもそも要らないかを疑う
- **作ったら台帳に書く。** ここに書かれていないスキルは、3ヶ月後に存在を忘れます

## 外部サービスと繋ぐスキル

カレンダー・タスク・ノート・メールと繋ぐスキルは、この型には**同梱していません**。何と繋ぐかは人によって違うし、繋がない状態でも仕組みは完結するからです。

繋ぐ場合は `GETTING-STARTED.md` の「外部サービスと繋ぐ」を見てください。作るときは**行動原則の非対称ルール**（追加は自由・消える操作は毎回確認）をスキル側でも守ること。
