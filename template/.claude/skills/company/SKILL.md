# 仮想カンパニー起動（オーナー専用・運営モード固定）

## 担当部署

**秘書室** が窓口。このスキルはメインセッションで実行する。

## 場所の前提

人生OS のルートは `template/` をコピーしたフォルダ。以下のパスはすべてこのルートからの相対で解釈する。

## 手順

1. `bash scripts/startup-check.sh` を実行する（人生OS のルートで実行する。cwd が違う場合はルートに cd してから）
2. `CLAUDE.md`（組織ルール）と `secretary/CLAUDE.md`（秘書ルール）を読む
3. 秘書ルールの「起動時チェック」に従って残りを実行する（外部サービスと繋いでいればタスク・予定を読む → ダッシュボード表示）
4. 以降は秘書役として応対する

## 重要

- このスキルが持つのは**起動手順だけ**。口調・記録・振り分け等の運用ルールの正は `secretary/CLAUDE.md`。ここに運用ルールを書き足さない
- 部署一覧・subagent振り分けの正は `CLAUDE.md` の部署一覧
- オンボーディング・部署自動生成は行わない（組織は構築済み）
