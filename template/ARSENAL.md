# 武器庫台帳（Arsenal）

外部（GitHub等）から取り込んだスキル・ナレッジの台帳です。**空の状態で出しています**——中身は自分が取り込んだものを書いてください。

> 実体は `.claude/skills/` に置き、`~/.claude/skills/` へ symlink を張ります（整合は起動時チェックが検査）。
> **自作スキルの台帳は `SKILLS.md`。ここには外部由来のものだけを載せます。**

## なぜ台帳を2つに分けるのか

自作と外部を同じ台帳に混ぜると、**出自が分からなくなります。** 出自が分からないと、次の3つができません。

1. **本家の更新を追えない** — 取得時のcommit SHAが無いと、差分が出ているかを確認できません
2. **ライセンスを確認できない** — 再配布するとき、自分のものでないファイルが混ざっていることに気づけません
3. **改変した箇所を思い出せない** — 本家を引き直すと、自分が足した部分が消えます

3つとも、**混ざってから気づくと復元できません。** だから分けるのは最初だけでよく、あとは足すときに置き場所を選ぶだけです。

## 追記フォーマット

部署ごとに見出しを作り、その下に1件ずつ足します。

```markdown
## ◯◯部

### スキル名

- **実体**: `.claude/skills/<name>/SKILL.md`
- **出典**: <URL>（作者名 / ライセンス / commit `SHA` / YYYY-MM-DD取得）
- **内容**: 何をするものか（1〜3行）
- **使いどころ**: どういうときに呼ぶか
- **改変**: 自分が変えた箇所（`## 担当部署` の追記など）
- **備考**: 取り込みの経緯や注意点
```

**`出典` の commit SHA と取得日は必ず書いてください。** ここを空にすると、本家が更新されたかどうかを確認する手段が消えます。あとから遡って調べるのは、たいてい無理です。

**`改変` も必ず書いてください。** 外部スキルは自分の組織のルールを知らないので、`## 担当部署` の追記が最低1箇所は入ります。書いておかないと、本家を引き直したときに黙って消えます。

## 取り込むときの注意

- **ライセンスを確認してから取り込みます。** ライセンスが見つからないものは、自分の環境で使うぶんは構いませんが、**再配布はできません**
- **同梱されている設定ファイルは、他人の環境のパスを指しています。** そのまま置くと動かない定義が1本増えるので、書き換えるか削除してください
- **取り込んだ時点で保守の対象になります。** 本家が更新されても自動では追いつきません。更新チェックを回す儀式を決めていないなら、取り込まないほうがよい場合もあります

---

_この台帳の使い方が分からなくなったら `SKILLS.md` の追記ルールを見てください。形式はほぼ同じで、違うのは出典の欄だけです。_
