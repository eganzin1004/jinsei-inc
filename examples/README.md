# examples/ — 記録の見本

ここに置いてあるのは、**架空の人物「ゆうすけ」の記録**です。**実際の記録ではありません。**

ゆうすけは38歳のフリーランスITディレクター（Web制作と小規模なシステム導入の進行管理・要件整理）という設定で、2026年2月から5月までの約4ヶ月ぶんが入っています。人物・取引先・数字・出来事はすべて創作で、実在の人物・団体とは関係がありません。

**型（コピーして使うもの）は `template/` にあります。** このフォルダはコピーして使うものではなく、「続けると何が溜まるのか」を読むためのものです。

## なぜ見本を置いているか

型だけを読むと、ルールファイルの集合にしか見えません。`decisions.md` に何を書くのか、`mindset-log.md` の話し言葉がどう `mindset.md` の判断軸になるのか、月次レビューで実際に何が起きるのか——これは実例がないと伝わりません。かといって本物の記録は出せないので、同じ粒度で創作しました。

## 読む順番

1. `decisions.md` — 4ヶ月ぶんの意思決定。撤回と廃止が混ざっています
2. `mindset-log.md` → `mindset.md` — 話し言葉の原文と、そこから精錬された判断軸
3. `reviews/2026-05.md` — 月次レビュー。最後に秘書役が本人の結論に反証します
4. あとは好きな順で

## 読むときの前提

- 取引先（A社・B社・C社・M社）はすべて架空です
- ゆうすけはコードを書きません。読むし、Git とチケットと仕様書は毎日触りますが、実装はしません。**エンジニアでなくてもこの型は回る**、という例として作ってあります
- **記録は歯抜けです。** 毎日は埋まっていません。3月の繁忙期と4月中旬はまるごと飛んでいます
- 成功だけが並んでいるわけでもありません。3件が撤回・廃止になっています
